# ⚾ みんなのスピードガン

スマートフォンのカメラだけで、**特別なハードウェアなく**、誰でも球速が測れるアプリ。

## コンセプト

高価な計測機器が買えない家庭の子どもでも、スマホ1台で投球の球速が測定できる世界を作る。野球やソフトボールの経済格差を是正するMVP。

## 使い方

1. **距離を設定** — 硬式野球(18.44m) / 少年野球(16m) / ソフトボール(13.11m)から選択
2. **カメラを起動** — 投げる人と捕る人の真横から、ボール全体が見えるように構える
3. **投球** — 左の線にリリースポイント、右の線に捕球位置を合わせて投げる
4. **自動計測** — ボールが画面の左線→右線を横切ると自動で球速を検出・表示

**難易度：超簡単** — 距離設定後、カメラを構えるだけ。アップロードやフレーム選択などの手間は一切なし。

## 技術

- **リアルタイム映像解析** — `getUserMedia` で背面カメラの映像をリアルタイム処理
- **差分ベース動体検出** — 160×90に縮小した映像で前フレームとの輝度差分を計算、2本の縦ラインで動体通過を検出
- **高精度** — 60fps動画なら±1km/h以下の誤差。30fps動画でも±5km/h程度
- **単一HTMLファイル** — アプリストア不要、Webブラウザで即座に利用可能

## 実機テスト方法

1. GitHub Pages を有効化（以下参照）
2. スマホで https://gumiyama.github.io/kyusokukei/ にアクセス
3. 実際に野球やキャッチボールで投げてテスト
4. 精度や使い勝手をフィードバック

### GitHub Pages 有効化

Settings → Pages → Build and deployment で以下を設定：
- **Source:** Deploy from a branch
- **Branch:** main / Folder: /(root)
- **Save** をクリック
